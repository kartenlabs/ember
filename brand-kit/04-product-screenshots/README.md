# Product screenshots

These are captures of the implemented Ember app, taken from a local production build in an isolated browser context. Capture date: 8 September 2026. The staged browser clock and seed data are reproducible in `07-source/render.mjs`.

- Desktop capture widths: 1440 px.
- Mobile capture width: 390 px.
- Captures use full-page height; see the manifest for exact dimensions.
- Task labels and session history are illustrative sample data.
- The timer is paused so the screenshot is stable.
- External YouTube visuals are replaced with a neutral “external media omitted” area in the capture context. App code is not changed. The actual stream's text attribution remains visible.
- These images are not user research evidence, analytics results, or photographs of real customer sessions.

Use the raw images for documentation. Use the composed covers and showcase images in `05-case-study` for presentation. Keep the sample-data note wherever the session log could be mistaken for a result.
