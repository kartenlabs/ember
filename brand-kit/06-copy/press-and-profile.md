# Press and profile copy

## One line

Ember is a quiet pomodoro timer with an optional ambient soundtrack, by kartenlabs.

## Short description

Ember offers adjustable focus and break lengths, five synthesized chimes, Night and Daylight themes, and a session log stored in the browser. An optional ambient station sits beside the timer. No account is required.

## Longer description

Ember is a calm browser-based pomodoro timer from kartenlabs. A warm pixel interface keeps the countdown, work/break rhythm, and playback controls close at hand. Focus, short-break, and long-break lengths are adjustable; five completion chimes can be previewed before use. The app supports two themes, fullscreen sessions, keyboard controls, and a local log. The optional ambient station currently features Claude FM, published by Claude and embedded through YouTube. Ember is independent of Anthropic and does not host the station audio.
